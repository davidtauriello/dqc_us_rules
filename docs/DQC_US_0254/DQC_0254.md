# Unnecessary Custom Elements in Schedule III Real Estate and Accumulated Depreciation
Rule ID: DQC.US.0254  
Status: Proposed  
Public Review Release date: TBD  
Effective date: TBD

## Rule Function

**Purpose:**

The purpose of Rule DQC.US.0254 is to identify unnecessary custom (extension) elements and axes used to tag Schedule III Real Estate and Accumulated Depreciation (SEC Regulation S-X 12-28).

**Conditions:**

Assertion 10974 fires when a Schedule III section includes an extension line item element (non-abstract item, not an axis, member or table) that has facts reported in the filing. A Schedule III section is any presentation network that:

1. Has the same role as a `srt:RealEstateAndAccumulatedDepreciationByPropertyTable` table, or
2. Has a role description containing "Schedule III", or
3. Is a "- Schedule -" section with a role description containing "Real Estate and Accumulated Depreciation".

Assertion 10975 fires when the table `srt:RealEstateAndAccumulatedDepreciationByPropertyTable` includes an extension axis.

Extension members are not evaluated, as each property is expected to be represented by a filer defined member.

## Problem Solved by the Rule

The US GAAP and SRT taxonomies include elements for each column required in Schedule III, including:

| Column | Element |
|---|---|
| Encumbrances | `srt:RealEstateAndAccumulatedDepreciationAmountOfEncumbrances` |
| Initial cost - land | `RealEstateAndAccumulatedDepreciationInitialCostOfLand` |
| Initial cost - buildings and improvements | `RealEstateAndAccumulatedDepreciationInitialCostOfBuildingsAndImprovements` |
| Costs capitalized subsequent to acquisition | `RealEstateAndAccumulatedDepreciationCostsCapitalizedSubsequentToAcquisitionImprovements`, `...CarryingCosts` |
| Gross amount - land | `RealEstateAndAccumulatedDepreciationCarryingAmountOfLand` |
| Gross amount - buildings and improvements | `RealEstateAndAccumulatedDepreciationCarryingAmountOfBuildingsAndImprovements` |
| Gross amount - total | `RealEstateGrossAtCarryingValue` |
| Accumulated depreciation | `RealEstateAccumulatedDepreciation` |

The taxonomy also contains the elements used to reconcile real estate and accumulated depreciation, and the axes needed to identify the property, property type and location. Custom elements are therefore unnecessary and reduce comparability.

## Example Rule Message

**10974:** The Schedule III Real Estate and Accumulated Depreciation section "0000099 - Schedule - Schedule III - Real Estate and Accumulated Depreciation (Details)" uses the following extension element(s): abc:RealEstateGrossAmountOfLandAndBuildings. The US GAAP taxonomy includes elements for each of the columns required in Schedule III ... Please replace the extension element(s) with the appropriate US GAAP or SRT taxonomy element.

**10975:** The Schedule III table srt:RealEstateAndAccumulatedDepreciationByPropertyTable in the section "0000099 - Schedule - Schedule III - Real Estate and Accumulated Depreciation (Details)" uses the following extension axis: abc:PropertyNameAxis. ... Please replace the extension axis with the appropriate taxonomy axis.

Rule Element Id: 10974  
Rule version: 32.0.0RC1

## Rule element ID index  
The rule element ID is used to identify unique elements or combinations of elements tested in the rule.

|Rule Element ID|Element|
|--- |--- |
| DQC.US.0254.10974 | Extension line item elements in Schedule III |
| DQC.US.0254.10975 | Extension axes on `srt:RealEstateAndAccumulatedDepreciationByPropertyTable` |

## Technical Details

- Extension elements are identified using the `is_extension` function against `$ALL_BASE_TAXONOMIES_ELTS`.
- Line items are restricted to non-abstract concepts in the `xbrli:item` substitution group, which excludes tables, axes and line item abstracts.
- Only extension elements with facts in the filing are reported (assertion 10974).

The rule exists in the 2026 US GAAP taxonomy version.
