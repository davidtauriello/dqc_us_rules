# Common Roll Forwards Do Not Calculate
Rule ID: DQC.US.0255  
Status: Proposed  
Public Review Release date: TBD  
Effective date: TBD

## Rule Function

**Purpose:**

The purpose of Rule DQC.US.0255 is to check that common roll forwards reported in a filing calculate, i.e. that the opening balance plus the movements in the period equals the closing balance.

**Conditions:**

Assertion 10976 checks roll forwards where the taxonomy defines a single net change element. It fires when *opening balance + net change ≠ closing balance* (outside a tolerance based on decimals). The roll forwards checked are:

| Balance Element | Net Change Element |
|---|---|
| `Goodwill` | `GoodwillPeriodIncreaseDecrease` |
| `UnrecognizedTaxBenefits` | `UnrecognizedTaxBenefitsPeriodIncreaseDecrease` |
| `DeferredTaxAssetsValuationAllowance` | `ValuationAllowanceDeferredTaxAssetChangeInAmount` |
| `AssetRetirementObligation` | `AssetRetirementObligationPeriodIncreaseDecrease` |
| `DefinedBenefitPlanBenefitObligation` | `DefinedBenefitPlanBenefitObligationPeriodIncreaseDecrease` |
| `DefinedBenefitPlanFairValueOfPlanAssets` | `DefinedBenefitPlanFairValueOfPlanAssetsPeriodIncreaseDecrease` |
| `ProductWarrantyAccrual` | `ProductWarrantyAccrualPeriodIncreaseDecrease` |
| `RestructuringReserve` | `RestructuringReservePeriodIncreaseDecrease` |
| `CashCashEquivalentsRestrictedCashAndRestrictedCashEquivalents` | `CashCashEquivalentsRestrictedCashAndRestrictedCashEquivalentsPeriodIncreaseDecreaseIncludingExchangeRateEffect` |
| `RealEstateGrossAtCarryingValue` | `RealEstatePeriodIncreaseDecrease` |
| `RealEstateAccumulatedDepreciation` | `RealEstateAccumulatedDepreciationPeriodIncreaseDecrease` |

Assertion 10977 checks the share option roll forward:

*Options outstanding (start) + Granted − Exercised − Forfeited and expired + Other increases (decreases) = Options outstanding (end)*

using `ShareBasedCompensationArrangementByShareBasedPaymentAwardOptionsOutstandingNumber`, `...OptionsGrantsInPeriodGross`, `StockIssuedDuringPeriodSharesStockOptionsExercised`, `...OptionsForfeituresAndExpirationsInPeriod` (or `...OptionsForfeituresInPeriod` + `...OptionsExpirationsInPeriod`) and `...OptionsOtherIncreasesDecreasesInPeriod`.

Assertion 10978 checks the nonvested equity instruments other than options roll forward (e.g. RSUs):

*Nonvested (start) + Granted − Vested − Forfeited = Nonvested (end)*

using `ShareBasedCompensationArrangementByShareBasedPaymentAwardEquityInstrumentsOtherThanOptionsNonvestedNumber`, `...GrantsInPeriod`, `...VestedInPeriod` and `...ForfeitedInPeriod`.

## Problem Solved by the Rule

Roll forwards are not represented in the XBRL calculation linkbase, so calculation validation does not detect when the opening balance, movements and closing balance are inconsistent. Inconsistencies are usually caused by incorrect signs on movements (for example a decrease entered as a positive value), period errors (an opening balance tagged with the wrong date) or dimensional mismatches.

## Example Rule Message

The roll forward of Goodwill does not calculate. The opening balance of Goodwill plus the change in the period reported using GoodwillPeriodIncreaseDecrease should equal the closing balance of Goodwill.

Opening balance (2024-12-31) : 1,200,000,000  
Change in period (2025-01-01 to 2025-12-31) : 150,000,000  
Expected closing balance : 1,350,000,000  
Reported closing balance (2025-12-31) : 1,050,000,000

Please check that the values of the opening balance, closing balance and change in the period are correct, that they have been reported with the correct sign, and that the facts are reported with the same dimensions.

Rule Element Id: 10976  
Rule version: 32.0.0RC1

## Rule element ID index  
The rule element ID is used to identify unique elements or combinations of elements tested in the rule.

|Rule Element ID|Element|
|--- |--- |
| DQC.US.0255.10976 | Single net change roll forwards (see table above) |
| DQC.US.0255.10977 | Share option roll forward |
| DQC.US.0255.10978 | Nonvested equity instruments other than options roll forward |

## Technical Details

- The duration movement fact anchors each check. The opening balance is the instant at the start of the movement period and the closing balance is the instant at the end of the movement period.
- All facts in a roll forward must have matching dimensions and units (Xule implicit alignment).
- If the opening or closing balance is not reported the rule does not run.
- Missing movement components (other than the anchor) are treated as zero.
- Tolerance uses `tolerance_for_decimals` with a factor of 2.
- Additional roll forwards can be added to the constant `$SIMPLE_ROLL_FORWARDS`.

The rule exists in the 2026 US GAAP taxonomy version.
