# BDC Investment Income Tagged with Nonoperating Interest and Dividend Elements
Rule ID: DQC.US.0256  
Status: Proposed  
Public Review Release date: TBD  
Effective date: TBD

## Rule Function

**Purpose:**

The purpose of Rule DQC.US.0256 is to ensure that Business Development Companies (BDCs) tag investment income from interest and dividends with the operating income elements rather than the nonoperating investment income elements.

**Conditions:**

The rule only runs for BDC filings, identified by `$BDC_FLAG` (the filing includes a Schedule of Investments presented as a financial statement).

| Assertion | Fires when the BDC reports | Appropriate element |
|---|---|---|
| 10979 | `InvestmentIncomeInterest` | `InterestIncomeOperating` |
| 10980 | `InvestmentIncomeDividend` | `DividendIncomeOperating` |
| 10981 | `InvestmentIncomeInterestAndDividend` | `InterestAndDividendIncomeOperating` |

## Problem Solved by the Rule

The SEC Division of Economic and Risk Analysis (DERA) identified that BDCs erroneously tag the "Investment income – interest" and "Investment income – dividend" line items in the consolidated statements of operations with `InvestmentIncomeInterest` and `InvestmentIncomeDividend`. These elements are defined as income on **nonoperating** securities. For a BDC investment income is the primary operating activity, so the appropriate elements are `InterestIncomeOperating` and `DividendIncomeOperating`.

See: [DERA Data Quality Report – Inappropriate elements used to tag BDC consolidated statements of operations](https://www.sec.gov/about/divisions-offices/division-economic-risk-analysis/260827-dqr-inappropriate-elements-used-tag-bdc-consolidated-statements-operations)

## Example Rule Message

The filer is a business development company and has reported a value of 85,000,000 using the element InvestmentIncomeInterest. This element is defined as interest income on nonoperating securities. For a business development company interest earned on investments is operating income and should be tagged using the element InterestIncomeOperating. Please replace the element InvestmentIncomeInterest with InterestIncomeOperating.

Rule Element Id: 10979  
Rule version: 32.0.0RC1

## Rule element ID index  
The rule element ID is used to identify unique elements or combinations of elements tested in the rule.

|Rule Element ID|Element|
|--- |--- |
| DQC.US.0256.10979 | `InvestmentIncomeInterest` |
| DQC.US.0256.10980 | `InvestmentIncomeDividend` |
| DQC.US.0256.10981 | `InvestmentIncomeInterestAndDividend` |

## Technical Details

- The rule reports every fact of the listed elements in a BDC filing, regardless of dimensions, since the nonoperating classification does not apply to a BDC's investment income.
- Assertion 10981 was added to cover the combined interest and dividend element, which has the same issue.

The rule exists in the 2026 US GAAP taxonomy version.
