# Inappropriate Axes Used in Schedule III Real Estate and Accumulated Depreciation
Rule ID: DQC.US.0253.10973  
Status: Proposed  
Public Review Release date: TBD  
Effective date: TBD

## Rule Function

**Purpose:**

The purpose of Rule DQC.US.0253 is to ensure that property level information in Schedule III Real Estate and Accumulated Depreciation (SEC Regulation S-X 12-28) is tagged using the appropriate axes.

**Conditions:**

Assertion 10973 fires when the Schedule III table `srt:RealEstateAndAccumulatedDepreciationByPropertyTable` includes any of the following axes:

| Inappropriate Axis |
|---|
| `BusinessAcquisitionAxis` |
| `RealEstatePropertiesAxis` |
| `PropertyPlantAndEquipmentByTypeAxis` |
| `srt:ScheduleOfEquityMethodInvestmentEquityMethodInvesteeNameAxis` |

## Problem Solved by the Rule

Schedule III reports information by individual property. The appropriate axis to identify each property is `srt:RealEstateAndAccumulatedDepreciationDescriptionOfPropertyAxis`. When needed, the property type can be tagged using `srt:MortgageLoansOnRealEstateDescriptionTypeOfPropertyAxis` and the location can be tagged using `srt:StatementGeographicalAxis`.

Filers have been using axes intended for other purposes, such as business combinations, PP&E classes or equity method investees, to identify properties in Schedule III. This makes the data inconsistent across filers and prevents users from extracting property level data.

| Purpose | Appropriate Axis |
|---|---|
| Property | `srt:RealEstateAndAccumulatedDepreciationDescriptionOfPropertyAxis` |
| Property type | `srt:MortgageLoansOnRealEstateDescriptionTypeOfPropertyAxis` |
| Location | `srt:StatementGeographicalAxis` |

## Example Rule Message

The Schedule III table srt:RealEstateAndAccumulatedDepreciationByPropertyTable in the section "0000099 - Schedule - Schedule III - Real Estate and Accumulated Depreciation (Details)" includes the axis RealEstatePropertiesAxis. This axis should not be used to identify properties reported in Schedule III Real Estate and Accumulated Depreciation. The appropriate axis to identify each property in this schedule is srt:RealEstateAndAccumulatedDepreciationDescriptionOfPropertyAxis. When needed, the type of property can be identified using the srt:MortgageLoansOnRealEstateDescriptionTypeOfPropertyAxis and the location of the property can be identified using srt:StatementGeographicalAxis. Please replace the axis RealEstatePropertiesAxis with the appropriate axis.

## Technical Details

- Schedule III is identified by the hypercube `srt:RealEstateAndAccumulatedDepreciationByPropertyTable`.
- The inappropriate axes are defined in the constant `$SCHEDULE_III_INCORRECT_AXES` and can be extended.
- The rule reports once per Schedule III table, listing all inappropriate axes found.

The rule exists in the 2026 US GAAP taxonomy version.
